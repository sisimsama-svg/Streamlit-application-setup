# نظارات مسلم — Moslem Optics، باب اللوق

تطبيق بايثون بواجهة Streamlit بهوية المحل: أبيض، رمادي فحمي، ونعناعي فاتح.

- متجر نظارات مع أسعار وسلة شراء
- تجربة النظارة على صورة الوجه عبر تحديد العينين وتركيب إطار شفاف
- توليد صور النظارات وتثبيت المكتبات تلقائياً

## التشغيل على ويندوز

انقر نقراً مزدوجاً على `run.bat` أو نفّذ من الطرفية:

```bat
python -m pip install -r requirements.txt
python generate_assets.py
python -m streamlit run app.py
```

ثم افتح الرابط الذي يظهر، عادة `http://localhost:8501`.

## الاستخدام

1. من **المتجر** اختر نظارة وأضفها للسلة أو اضغط **تجربة**.
2. في **تجربة النظارة** ارفع صورة وجه أمامية واضحة أو التقط صورة بالكاميرا.
3. اختر الإطار فيُركَّب تلقائياً على العينين. يمكن تحميل صورة النتيجة.
4. من **السلة** أكمل بيانات التوصيل (طلب تجريبي محلي بدون بوابة دفع).

أفضل النتائج مع صورة أمامية، إضاءة جيدة، والوجه غير مغطى.

## مجلد البيانات والنشر

الافتراضي مجلد `data` داخل المشروع، ومسارات ويندوز المحلية تبقى كما هي. لنقل الكتابة إلى مجلد خارج التثبيت (قرص دائم مثلاً) عيّن قبل التشغيل:

```bat
set MOSLEM_DATA_DIR=D:\moslem-data
```

على Streamlit Community Cloud القرص مؤقت: الطلبات والإيصالات والشعارات تختفي بعد إعادة التشغيل ما لم تُربط لاحقاً بقاعدة خارجية. إذا غابت ملفات البيانات يُعاد كتالوج نظارات مسلم وواتساب `https://wa.me/201148005679` وإنستغرام وفيسبوك الرسميان.

### GitHub ثم Streamlit Community Cloud

1. أنشئ مستودعاً عاماً فارغاً على GitHub من دون README جاهز.
2. إن لم يُعرف الأمر `git` فثبّت Git for Windows ثم أعد فتح الطرفية. من مجلد المشروع: `git init` ثم `git branch -M main` إن لم يكن Git مهيأ.
3. `.gitignore` يمنع رفع الطلبات والروشتات والإيصالات والشعارات و`data/vendors.json` و`data/admin.json` وملف exe. لا تحذف هذه الملفات من الجهاز.
4. `git add .` ثم تأكد عبر `git status` أن ملفات العملاء غير ظاهرة، ثم commit و`git remote add origin` و`git push -u origin main`.
5. من https://share.streamlit.io سجّل الدخول بـ GitHub، New app، الفرع `main`، الملف الرئيسي `app.py` (لا تستخدم `shop.py`). المنصة تثبّت `requirements.txt`. `app.py` يقدّم المتجر كـ PWA: `manifest.json` و`service-worker.js` وأيقونة الشعار بلون `#059669`، فيظهر «أضف إلى الشاشة الرئيسية» من المتصفح.
6. الرابط بعد النشر يكون على الشكل `https://اسم-تختاره.streamlit.app`.

Render كبديل: خدمة ويب Python، وأمر التشغيل:

```bash
streamlit run app.py --server.port $PORT --server.address 0.0.0.0
```
