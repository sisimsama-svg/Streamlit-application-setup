# نظارات مسلم — باب اللوق

متجر إلكتروني لمحل واحد: نظارات مسلم. لا يوجد تسجيل لمحلات أو تجار آخرين.

التشكيلة تشمل النظارات الطبية والشمسية، وصفحة لكل إطار، وسلة، وإتمام طلب بالتوصيل حسب المحافظة. التجربة الحية تفتح كاميرا الجهاز وتثبّت الإطار على العينين داخل المتصفح، من غير رفع الصورة إلى الخادم.

## التشغيل

انقر مرتين على `run.bat`، أو من مجلد المشروع:

```bat
py -3 generate_assets.py
py -3 server.py
```

ثم افتح `http://127.0.0.1:8765`.

أول تشغيل للتجربة الحية يحتاج اتصالاً لتحميل نموذج تتبّع الوجه في المتصفح. بعد السماح للكاميرا يظهر الإطار على الوجه مباشرة، ويمكن تغيير حجمه وارتفاعه والتقاط صورة.

الطلبات تُحفظ في `data/orders.json`. الدفع عند الاستلام أو تحويل InstaPay / فودافون كاش ثم كتابة رقم العملية. لا توجد بوابة دفع إلكتروني.

## النشر على استضافة مجانية

الملفات الجاهزة:

- `render.yaml` و`Procfile` و`requirements-web.txt` لمنصة Render
- `Dockerfile` لأي استضافة تقبل صورة Docker، مثل Koyeb

الخدمة تستمع على `0.0.0.0` والمنفذ الذي تحدده المنصة في المتغير `PORT`. فحص الجاهزية: `/health`.

على Render: ارفع المشروع إلى مستودع Git عام، ثم New Web Service واختر المستودع. المنصة تقرأ `render.yaml`. الخطة المجانية تنام بعد فترة خمول، وأول زيارة بعدها قد تتأخر نحو دقيقة. القرص مجاني ومؤقت: الطلبات تبقى طالما الخدمة لم تُعد بناؤها من جديد.

أول فتح لصفحة التجربة الحية يحتاج إنترنت في متصفح الزائر لتحميل نموذج تتبع الوجه.
